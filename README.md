# בוט וואטסאפ · מוק-אפ משימה 4

מוק-אפ סטטי (Preact + htm מ-CDN, בלי בנייה) למשימה 4 בסקופ: אינטגרציית בוט וואטסאפ. העסק לדוגמה הוא קליניקה של מטפל רגשי, "מרחב שקט".

באותו ריפו, מוק-אפ נפרד: הכריש בוואטסאפ האישי של המשתמש (`shark.html`). הוא לא חלק משלב 13: הכרטיס שלו נעול בדף הבית עד התשלום, ומיד אחרי התשלום נפתחת חלונית חגיגית להוספה.

המוק-אפ נפתח בשלב 13, כמו בתוך המערכת, ומכאן מגיעים לכל השאר דרך דף הבית. שני דברים בלבד שייכים למוק-אפ ולא למוצר: הטלפון של הליד במסגרת המקווקוות בעמוד הלידים, והערות למפתחים (Shift+D).

## הרצה מקומית

```bash
python -m http.server 4186
```

בווינדוס אפשר ללחוץ פעמיים על `open-mockup.bat`.

## מה יש כאן

| קובץ | מה בו |
| --- | --- |
| `src/engine.js` | ספר החוקים: מה קורה לכל הודעה, בסדר המחייב |
| `src/step.js` | שלב 13 על חמשת חלקיו, וסיום הפרק |
| `src/leads.js` | עמוד הלידים: שיחות, אישור וטבלה, והטלפון של הליד |
| `shark.html`, `src/shark-main.js`, `src/shark.js` | המוק-אפ הנפרד של הכריש: דף הבית הנעול, מסך התשלום, החלונית, דוגמת שיחה והגדרות |
| `src/home.js`, `src/settings.js` | דף הבית וההגדרות |
| `src/state.js` | נתוני הדוגמה ומקרי הקצה |
| `src/data.js` | הטקסטים והמשתמשים לדוגמה |
| `src/devnotes.js` | הערות למפתחים (Shift+D) |

## פרמטרים בקישור

הבוט: `?view=step|live|home|settings`, `?screen=opening|link|hours|opening_msg|answers|test|done`, `?case=nocode|two|closed|human|voice|window|stop|aidown|ended`, `?user=f|m`, `?embed=1`.

הכריש (`shark.html`): `?view=home|pay|chat|settings`, `?paid=1`, `?welcome=1`, `?user=f|m`, `?embed=1`.

ההתאמה לפי משמעות מדומה כאן ברשימות מילים. במערכת עצמה היא נעשית לפי משמעות, והכלל נשאר: בלי התאמה ברורה לא נשלחת תשובה מהרשימה. במקומה יוצאת לבד תשובת ההעברה, "שאלה טובה, העברתי לשירות לקוחות.", וההצעה של הכריש מחכה לאישור.
